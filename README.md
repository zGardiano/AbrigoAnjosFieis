# 🐾 Abrigo Anjos Fiéis

Website institucional desenvolvido para a **ONG Abrigo Anjos Fiéis** como parte da disciplina **Prática Extensionista IV**, conectando conhecimentos de desenvolvimento web a uma iniciativa de proteção animal.

O projeto tem como objetivo fortalecer a presença digital do abrigo, apresentar seu trabalho de resgate e cuidado de cães e facilitar o acesso a informações sobre adoção responsável e formas de contribuir.

## 💚 Sobre o projeto

O Abrigo Anjos Fiéis acolhe cães em situação de abandono e maus-tratos, oferecendo cuidados e buscando novos lares para os animais.

Desenvolvido em equipe, o website reúne a história da ONG, seus objetivos, os desafios enfrentados no dia a dia e os canais de contato com a comunidade.

A proposta é utilizar a tecnologia para dar mais visibilidade à causa e aproximar o abrigo de possíveis adotantes e apoiadores.

## 🖥️ Recursos do site

- **Página inicial:** apresentação do abrigo e galeria de fotos dos cães.
- **Cães:** informações sobre adoção e acesso ao Instagram da ONG para acompanhar os animais.
- **Doações:** orientações para contribuir via Pix, com QR Code, e informações para visitar o abrigo.
- **Sobre:** história da organização, sua missão e os desafios de manter os cuidados com os animais.
- **Layout responsivo:** estilos adaptados a diferentes tamanhos de tela e menu de navegação para dispositivos móveis.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo das páginas.
- **CSS3:** estilização, layouts com Flexbox e Grid e adaptação para dispositivos móveis.
- **JavaScript:** interação do menu de navegação.

O projeto é um site estático, sem necessidade de backend, banco de dados ou instalação de dependências.

## 🚀 Como visualizar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/zGardiano/AbrigoAnjosFieis.git
   ```

2. Acesse a pasta:

   ```bash
   cd AbrigoAnjosFieis
   ```

3. Abra o arquivo `index.html` no navegador.
